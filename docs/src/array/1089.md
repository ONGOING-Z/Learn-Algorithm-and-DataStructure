## [Problem Info][problem_link]
复制出现的0。使用插入排序的思路，将元素往后移。

## Attention

## Answer - 1

- java

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) { // (1)这里为什么是长度-1，因为最后一个元素不需要判断
            if (arr[i] == 0) {
                // 将 i+1 ~ n-2 右移 // (2) 为什么是i+1, n-2, n-2是倒数第二个元素，会把倒数第一个给覆盖
                for (int j = arr.length - 2; j >= i+1; j--) {
                    arr[j+1] = arr[j];
                }
                arr[i+1] = 0;
                i++;
            }
        }
    }
}
```
- time: 12ms
- beat 28%
- big O: O(n)
