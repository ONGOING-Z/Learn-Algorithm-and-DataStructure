## Attention
* 至多只能有一种字符的频次是奇数，如果有两个，那就不能构成回文字符串
* 所以
  * 统计每种字符的频次
  * 查看为奇数频次的字符种类数量

## Answer - 1

- java
```java
class Solution {
    public boolean canPermutePalindrome(String s) {
        Map<String, Integer> map = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            map.put(ch + "", map.getOrDefault(ch + "", 0) + 1);
        }
        int oddCount = 0;
        for (Integer count : map.values()) {
            if (count % 2 == 1) {
                oddCount++;
            }
            if (oddCount > 1) {
                return false;
            }
        }
        return true;
    }
} 
```
