# Data Structures and Algorithms Learning Repository

> **学习数据结构与算法的综合资源库**

## 📖 简介

数据结构和算法是计算机科学的基础。本仓库总结了基础知识，并提供了大量的实践练习来加深理解和熟练度。

正如小甲鱼所说：**数据结构就是关系**

## 🚀 快速开始

### 学习路径

1. **理论学习**: 从 `docs/theory/` 开始学习基础概念
2. **代码实现**: 查看 `src/` 中的各种语言实现
3. **实战练习**: 在 `practice/` 中找到相关练习题
4. **工具使用**: 使用 `tools/` 中的脚本辅助学习

### 主要内容

#### 数据结构
- **线性结构**: 数组、链表、栈、队列
- **树形结构**: 二叉树、平衡树、堆
- **图形结构**: 有向图、无向图、网络

#### 算法
- **排序算法**: 冒泡、选择、插入、快排、归并等
- **搜索算法**: 线性搜索、二分搜索、深度优先、广度优先
- **动态规划**: 背包问题、最长公共子序列等
